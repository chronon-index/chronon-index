1. WHAT WAS COMPUTED
--------------------
Estimator E2 (RESEARCH_PROGRAM Part IX):

    S = sum over age bands of  N_band * e(mid(band))

- Band midpoint by the uniform-within-band assumption: a band of integer
  ages [lo, hi] covers exact ages [lo, hi+1), midpoint (lo + hi + 1) / 2
  (0-4 -> 2.5, 5-9 -> 7.5, ..., 95-99 -> 97.5).
- The open-ended 100+ band has no width; convention lo + 2.5 = 102.5 was
  used. This choice is inert: e() is flat beyond the last anchor (85), so
  any midpoint >= 85 yields e(85).
- e() by piecewise-linear interpolation on the exact-age anchors of the WHO
  abridged global life table (anchors at exact ages 0, 1, 5, 10, ..., 85);
  flat beyond age 85.
- ALL arithmetic in Decimal, precision 34, ROUND_HALF_EVEN, from the moment
  values leave parsing (GHO JSON parsed with parse_float=Decimal; CSV values
  parsed directly to Decimal). No floats anywhere in the computation.

Runner: seed/tly_v0_calc.py (Python 3.12, stdlib only).
  --fetch          fetch + snapshot + manifest, then compute
  (default)        offline recompute from the committed snapshot
Output: seed/results_v0.json (Decimal-as-string; deterministic rendering —
two offline runs were diffed and are byte-identical; invariant P5).

4. DISCUSSION OF DEVIATIONS (honest; hypotheses labeled as unverified)
----------------------------------------------------------------------
S (both tables), E-bar, N, spend: reproduced exactly at the published 4-dp
precision, with no parameter tuning — the estimator was computed exactly as
specified in RP Part IX E2 and the numbers came out matching. This strongly
supports that the lost original used this same source pair (WHO GHO global
abridged ex; OWID/WPP-2024 5-year world population, 2023) and the same
banding/interpolation choices.

mint: achieved 9.6603 B vs target 9.6606 B (-0.0026%). The reconstruction
used mint = B_2023 * e_2019(0) with OWID births 132,110,264. Unverified
hypotheses for the 0.0003 B gap, each with the check that would settle it:
  (h1) The original took births from a different WPP 2024 surface (e.g. the
       UN demographic-indicators CSV or data portal), which can differ from
       OWID's processed series by rounding/aggregation. Check: fetch UN WPP
       2024 demographic indicators for 2023, world births, and recompute.
       (Implied births for an exact match: 9.6606e9 / 73.123374469 =
       ~132,113,706 — about 3,442 above the OWID value.)
  (h2) The original used a different births window or year convention
       (mid-2022 to mid-2023 vs calendar 2023). Check: same fetch as h1
       with both conventions.
  (h3) The original used e(0) at a different precision or from a different
       series (e.g. the WHO GHE life expectancy at birth indicator rather
       than the life-table ex row). Check: fetch WHOSIS_000001 (life
       expectancy at birth) global 2019 and compare against 73.123374469.
None of these is asserted. The core S / E-bar / N anchors do not depend on
births and are unaffected.

drift (+1.0394 B) and g (+0.7197 %/yr): NOT REPRODUCED in this pass. They
require dE-bar/dt — E-bar evaluated at two adjacent time points (successive
population structures and/or successive life tables), which this pass did
not fetch. The identity (RP Part IX E4) is
  dS/dt = B e(0) - N + N dE-bar/dt   (- excess-death term)
so with mint and spend reproduced, drift is the one remaining term; it
should be reconstructed together with METHODOLOGY_v0.md, which defined the
exact vintage pair and differencing convention (that definition was lost
with the original — reconstructing it from DECISIONS.md alone would be
guessing, which is forbidden).
